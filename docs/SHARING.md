# 项目介绍与演示示例

以下文案可按自己的语气修改后使用。人数、流派数与关系数来自当前公开数据快照，更新资料后请一并核对。

## 简短介绍

我把「西方哲学思想脉络图」开源了：通过一张可搜索、可切换布局的思想地图，探索 413 位哲学家、115 个流派与思想传承关系。无需登录或安装，打开网页就能使用，也欢迎附来源纠错。

- 在线体验：https://western-philosophy.inklinks.io/
- GitHub：https://github.com/adonisly/western-philosophy-map

## 面向读书伙伴的介绍

读西方哲学史时，我常想把人物、流派和思想之间的联系放到同一张图上看。这个开源交互图谱整理了 413 位哲学家、115 个流派和 131 条关系，可以搜索人物、阅读主要思想与著作，并切换世纪、流派和传承等布局。

可以先试一次：搜索「苏格拉底」或拼音首字母「sgld」，点击人物卡片阅读详情，再切换「传承」布局探索思想联系。学习资料持续整理中，重要论断仍需结合原著和可靠研究核对。

- 直接体验：https://western-philosophy.inklinks.io/
- 查看源码、Star 收藏或提交纠错：https://github.com/adonisly/western-philosophy-map

## 三个演示切入点

- **认识人物**：搜索苏格拉底，打开人物详情，展示主要思想、思想继承与后世影响。
- **梳理联系**：在传承布局中查看苏格拉底与柏拉图、柏拉图与亚里士多德的有向关系。连线展示的是快照中已录入的关系，并不穷尽思想史中的全部联系。
- **换一个观察角度**：先看默认布局，再切换世纪或流派布局，说明同一组人物可以按不同线索组织。
