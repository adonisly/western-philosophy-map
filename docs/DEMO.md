## 内容顺序

1. 项目简介与图谱总览。
2. 输入 `sgld`，使用拼音首字母搜索苏格拉底。
3. 选择搜索建议，自动定位人物卡片。
4. 打开详情，阅读生平、思想继承、主要思想与后世影响。
5. 切换世纪布局。
6. 一键探索实用主义流派。
7. 从苏格拉底入口查看传承布局。
8. 复制人物分享链接。
9. 浏览无需 JavaScript 的人物与流派索引。
10. 在线体验地址与开源仓库。
